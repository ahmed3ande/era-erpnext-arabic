# Translation Audit

The Era audit pipeline scans only the canonical source catalogs:

```text
arabic_translations/locale/source/<app>/ar.po
```

It never rewrites PO catalogs.

## Commands

```bash
python -m unittest -v tests/test_audit_translations.py
python scripts/audit_translations.py
python scripts/audit_translations.py --fail-on-placeholder
```

Reports are written deterministically under `reports/audit/` and uploaded by GitHub Actions as the `translation-audit` artifact.

## CI policy

- Unit-test failure blocks the PR.
- Catalog syntax and existing safety checks block the PR.
- Any validated placeholder mismatch blocks the PR.
- Linguistic findings generate review queues and artifacts but do not block the PR.
- False-positive fixes require a regression test.

## Review order

1. Placeholder errors
2. Untranslated entries
3. Fuzzy entries
4. Approved/rejected glossary conflicts
5. Accounting-related cross-app conflicts
6. English residue filtered to accounting screens
